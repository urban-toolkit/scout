# Use Cases

**SCOUT** includes three example use cases that demonstrate how the system can support different scenario-oriented urban decision-support workflows: alternative high-rise buildings for shadow analysis, nature-based flood mitigation, and exteme weather-aware routing. Together, they illustrate how SCOUT connects data layers, model execution, widgets, interactions, views, and comparisons into scenario-oriented decision workflows.

### Available:

- [Evaluating alternative high-rise configurations](use-cases/shadow.md)
- [Planning nature-based flood mitigation](use-cases/flooding.md)
- [Weather-aware route planning](use-cases/routing.md)
